## Introduction

### AD DS (Active Directory Domain Services)
**AD DS** is the core role in Windows Server that stores and manages information about users, computers, groups, and other network resources.

Think of AD DS as a central database for an organization.

#### What AD DS stores
- User accounts
- Computer accounts
- Groups
- Organizational Units (OUs)
- Printers
- Shared folders
- Group Policies (GPOs)
- Domain information


### Active Directory Recycle Bin
The **Active Directory Recycle Bin** allows administrators to restore accidentally deleted AD objects without needing a full backup.

Before Windows Server 2008 R2, if you deleted a user or OU, recovering it was much more difficult.


### Sharing
**Sharing** means making folders or printers accessible over the network.

Types of Permissions

#### Share Permissions
Control access over the network.

Levels:
- Read
- Change
- Full Control

#### NTFS Permissions
Control access on the file system.

Common permissions:
- Read
- Write
- Modify
- Full Control


#### Effective Permission
The user's actual access is the most restrictive combination of Share and NTFS permissions.
| Share        | NTFS   | Effective |
| ------------ | ------ | --------- |
| Full Control | Read   | Read      |
| Read         | Modify | Read      |
| Change       | Modify | Modify    |



### Enumeration
**Enumeration** is the process of **collecting detailed information** about a system, network, or Active Directory environment.

It is used by:
- System administrators
- Penetration testers
- Red Teams
- Security analysts
- Attackers

The goal is to understand what resources, users, services, and permissions exist.


#### Enumeration Tools
| Tool                                          | Purpose                                                           |
| --------------------------------------------- | ----------------------------------------------------------------- |
| Active Directory Users and Computers (ADUC)   | View and manage AD objects                                        |
| Active Directory Administrative Center (ADAC) | Modern AD management                                              |
| PowerShell (ActiveDirectory module)           | Query and manage AD                                               |
| `net user`                                    | List domain users (legacy command)                                |
| `net group`                                   | List domain groups                                                |
| `net view`                                    | View shared resources                                             |
| `nltest`                                      | Domain controller and trust information                           |
| `dsquery`                                     | Search AD objects                                                 |
| `BloodHound`                                  | Visualize AD relationships and attack paths (security assessment) |
| `SharpHound`                                  | Collect data for BloodHound                                       |
| `LDAP` queries                                | Retrieve directory information                                    |

##### What $ mean?
In Windows networking, the ``$`` symbol at the end of a shared folder name means it is a hidden administrative share:
| Hidden Share Feature        | Description                                                                                                | Purpose / Usage                                                  |
| --------------------------- | ---------------------------------------------------------------------------------------------------------- | ---------------------------------------------------------------- |
| **Hidden share**            | The shared folder is hidden from network browsing (it won’t appear in “Network” listings).                 | Prevents casual users from seeing the share.                     |
| **Still accessible**        | The share can still be accessed directly using its full path (e.g., `\\dc01-ad\ITDocs$`).                  | Allows access for users who already know the exact path.         |
| **Used for administration** | Typically used for IT management tasks such as system administration, backups, and sensitive data storage. | Provides controlled access for administrators and support tasks. |

Example:
- ``C$`` → Hidden share for the C: drive.
- ``ADMIN$`` → Hidden share pointing to the Windows folder.
- ``ITDocS$`` → A custom hidden share created by admins for IT documentation.
