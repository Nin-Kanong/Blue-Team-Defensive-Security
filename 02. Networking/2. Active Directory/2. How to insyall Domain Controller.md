### Active Directory Users and Computers (ADUC)
| Container                     | Purpose                                                                     |
| ----------------------------- | --------------------------------------------------------------------------- |
| **Builtin**                   | Contains built-in security groups (Administrators, Backup Operators, etc.). |
| **Computers**                 | Default location for computers that join the domain.                        |
| **Domain Controllers**        | Stores all Domain Controller (DC) computer accounts.                        |
| **ForeignSecurityPrincipals** | Contains users/groups from trusted external domains.                        |
| **Managed Service Accounts**  | Stores managed service accounts used by services and applications.          |
| **Users**                     | Default container for user accounts, groups, and service accounts.          |
